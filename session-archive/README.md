# Полный архив исходной рабочей сессии

Опубликован по прямому поручению владельца после первоначальной обезличенной версии навыка. Личные ссылки на исходники, локальные пути, журналы, скриншоты и снимки проектов сохранены без обезличивания.

- `session-evidence.zip.001` … `.007` — части точной копии ранее сохранённого локального архива: 680 рабочих файлов плюс служебный README самого архива, всего 681 запись. Большой файл разделён для надёжной загрузки через браузер; байты архива не изменены.
- `manifest.json` — полный перечень путей, размеров и SHA-256 каждого файла, а также контрольная сумма ZIP.

После скачивания папки выполните `python restore_session.py --output restored-session-evidence.zip`. Скрипт проверит каждую часть, соберёт исходный ZIP и сверит его общую контрольную сумму. Ничего не запускает из архива и не перезаписывает существующий файл.

Исходное локальное имя архива и README внутри него содержали пометку «НЕ ПУБЛИКОВАТЬ». Это историческая пометка; последующее явное поручение владельца разрешило публикацию данного архива.

Это сохранённые операционные материалы: контекст, журналы использованных эпизодов, рабочие Python/JSX/XML/JSON, сохранённые изображения и снимки проектов Premiere. Сами большие видео и аудиозаписи остались в исходных локальных папках; они не входили в этот архив. Снимки `.prproj` могут ссылаться на эти внешние медиа и не являются автономными комплектами с исходниками.

Наличие скриншотов и проектов не означает, что архив содержит каждый когда-либо просмотренный кадр или несохранённое изображение. Внутренние скрытые рассуждения модели не записывались и в архив не входят. Проверка типичных форматов секретов не обнаружила паролей/токенов доступа; это не универсальная гарантия автоматического анализа.

## Обязательная загрузка истории

По уточнённому требованию владельца архив используется **при каждом запуске навыка**, а в каждом новом чате координатор обязательно читает полный исходный контекст. Выполнить `python session-archive/bootstrap.py` из корня навыка. Скрипт проверяет все части и все 681 записи, разворачивает их в локальном кэше и выдаёт точные пути к полному контексту, журналу и актуальным правилам. Уже проверенные неизменённые файлы повторно не распаковываются; при каждом запуске их целостность проверяется заново.

Координатор читает полный исходный контекст и текущие правила один раз в новом чате, повторно — после потери этой информации при сжатии контекста. Сабагенты получают подтверждение bootstrap и прикладное задание, без дублирования всей истории на каждого работника. Все сохранённые журналы, изображения и проекты всегда доступны в кэше; это не означает просмотр каждого старого скриншота при каждом ролике.

Распакованные файлы отмечаются как временный кэш навыка. Команда «завершаем чат» может удалить этот кэш через проверяемый реестр; установленные части архива сохраняются. Следующий монтаж снова обязательно запустит bootstrap и восстановит историю из локальных частей без новой загрузки из сети.

Старые рабочие скрипты содержат абсолютные пути и одноразовые операции; не запускать их автоматически. Личные ссылки автора не дают другим пользователям разрешения использовать его исходники; для их роликов нужны собственные материалы и профиль. Полный сохранённый контекст помогает продолжать принятые решения, но не переносит скрытое внутреннее состояние модели.
