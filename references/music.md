# Selecting music and synchronizing edits

1. Verify the file exists and inspect actual container, sample rate, channels and duration. Extensions can be wrong. Decode full stereo 48k PCM WAV for Premiere and a short analysis window. Don't rename a compressed container to WAV.
2. Prefer a recognizable chorus/drop or approved verse **beginning with the complete first word**. Never choose a random mid-word/mid-verse cut merely to fit 30 seconds. Fit the last complete phrase and final fade. Ask only if a creative choice cannot reasonably be made from the supplied track; do not request approval for every boundary.
3. Listen to the actual stereo segment. Start analysis with a stereo-to-mono mix, e.g. `-ac 1`, but compare L/R if vocals disappear through phase cancellation. OVERDOZ's left-only transcription falsely missed early vocals; CUPSIZE's mono mix weakened vocals. Neither always-mono nor always-left is universal. Transcription is rough evidence of phrase boundaries, not exact lyrics or proof of listening.
4. Analyze sparse onset candidates first. High-band energy/positive spectral difference can help locate cymbals/hi-hats; stronger full/low-band accents usually suit the logo. Estimate tempo, then check actual accents and phase across start/middle/end. Silence, vocals and percussion confuse detectors. A mechanical BPM grid without checking audio is insufficient.
5. Keep two rhythms: seven logo stages on MAIN beats, combat anchors on an appropriate frequent subdivision (often hats/cymbals). User saying «плоские круглые пластины у барабанщика» means cymbals; it does not instruct logo to follow all hats. Choose 2–3 active moments/s when the song supports it. The approved POVOD and later generated CUPSIZE had still denser cuts; CUPSIZE was not separately recorded as approved. Don't universalize one song's subdivision.
6. Align the actual firing/hit/kill anchor to the accent, with the shot ending about 3 frames later. If desired musical anchor is output frame A and shot has N frames, start source at `source_anchor - (N-tail_frames)/fps`. Preserve exact boundaries when changing a shot later. Do not stretch idle tails to fill a sparse grid.
7. Check first syllable, every main logo hit, anchors on several cuts and the final full word in exported MP4. Fade cannot repair a word already truncated by the chosen range. Small 8ms audio entrance ramp may suppress clicks, not erase phonemes. Default outro is 2.814375s; shorten only when the music genuinely requires it.

Use `media_tools.py analyze` to write candidates to JSON. It does **not** identify choruses, trendy excerpts or verified instrument labels. Search official/available music information only when useful. Do not republish music, full lyrics or ASR transcripts with the skill. If the user supplies only a title, verify exact version/remix and obtain an accessible authorized source; don't silently substitute a cover or hallucinate a download.

Known historical selections are in examples/history-ledger.json. They are song-specific decisions, never a rule to reuse the same start time.
